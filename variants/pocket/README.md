# pocket 变体：0.1.5-pocket.2

此目录提交的是基于最初`0.1.0`（`03bf068fcecb2d11eb10b6ecb058db7ebeaa44a2`）迭代并在Edge + 暴力猴实测的独立变体，便于维护者审查、试用或后续择取功能。**不替换当前0.4.5主线，不将其降级为0.1.5，也不宣称本变体包含主线全部功能。**

## 主要能力

- 按具体个体预选培养候选池，自动配队及连败重配严格在池内进行；不足六只按实际人数，空池不补池外成员。
- 有效BST筛选、展示和评分统一：当前形态基础种族值总和 × 异色1.10 × 1.15^地下强化档数；保留小数，档数按游戏归一化到0—5。
- 手动目标支持数字、形态编号与名称；从游戏形态定义构建73个别名。基础种与形态独立判定捕获。
- 同章合并多个缺失目标，按实际生成节点决定本轮终点；捕获后缩短路线。洛托姆形态按static事件、天气/昼夜/前置/解锁判定，而非当作普通野生池。
- 缺失优先目标全部完成或暂不可刷时自动推图；条件恢复后回收集。战斗/待结算时等待，不因本轮10%事件未生成就切换模式。
- 八种增益树果与四种培育树果用途完整显示；培育树果保持手动使用，新增开关默认关闭。
- 正常拖拽入队、来源地区资格、合并联盟入口、取消/异常恢复、用户设置与草稿迁移、DOM单实例保护。

完整逐条对比见[CHANGELOG.md](CHANGELOG.md)。

## 安装与使用

在暴力猴或Tampermonkey中新建脚本，粘贴同目录`pokecatch-assistant.user.js`并保存。脚本只匹配两个游戏域名顶层页面，没有外部运行依赖或上游自动更新地址。

1. 停用主线或其他旧助手，刷新游戏；不要同时启动两个控制器。两者会使用相同的助手偏好键`pca.settings.v1`，切换版本前自行备份设置。
2. 若要限制培养成员，在“候选池”中选择个体、设置最低有效BST并保存。
3. 在“全图鉴”中填写优先目标，启用自动轮换，点击“开始全图鉴收集”。
4. 页面刷新后自动加载面板，任务按会话提示点击开始恢复；不保证刷新后自动开打。

本地已实际验证暴力猴加载来源、刷新后单实例、设置及草稿保留、正常配队与收集/推图双向切换。没有上传玩家存档、账号、候选个体ID或浏览器配置；也没有伪造捕获来宣称全部目标完成。

## 构建与测试

需要Node.js，无需安装运行依赖：

```bash
node variants/pocket/build.mjs
node --check variants/pocket/pokecatch-assistant.user.js
node --test variants/pocket/assistant.test.mjs
npm test
```

`game-data.json`固定为已验证的游戏`app.c0081498f2.js`/语言`01332b3d04`兼容数据，构建仅将其注入模板。`tests/pocket-variant.test.mjs`把55项变体回归和1项发布文件一致性检查接入原有`npm test`/CI；当前上游35项与新增56项共91项通过。

`game-reference.txt`是公开前端中用于差分测试的少量原始函数片段，不是完整游戏包，也不是可直接执行的模块；来源与SHA-256见`reference-provenance.json`。测试所有存档均为合成数据。`linkedom.worker.mjs`仅用于测试DOM，其ISC许可证保存在`linkedom.LICENSE`。

## 与当前主线的边界

上游已独立加入拖拽、地区限制、特殊形态、雾莲果及天气调度等能力；本地相对0.1.0的修复不能当作当前0.4.5仍未修复的问题。本变体提供的培养候选池、有效BST、同章静态形态合并及自动推图轮换可单独审阅。

本变体未移植主线后续的双语界面、四种任务入口、批量保留重复、特殊传说地点或168小时天气队列/刷钱等待策略。它沿用0.1.0架构，并保持已实测安装文件字节一致，便于复核。

锁屏/后台持续运行不在已解决范围，游戏版本变更也需要重新核验兼容数据。
